# NYPC 코드배틀 2025 - Yacht Dice AI

넥슨 NYPC 코드배틀 2025의 Yacht Dice AI 문제에 참가한 C# 기반 AI 프로젝트입니다.

## 프로젝트 정보

- **개발 기간:** 2025.07 ~ 2025.08
- **개발 형태:** 3인 팀 공모전
- **사용 기술:** C#, .NET
- **성과:** 681개 참가 팀 중 134위

## 담당 역할

AI 의사결정 알고리즘 설계와 구현을 담당했습니다.

- 현재 주사위와 남은 점수 칸 기반 기대값 계산
- 점수 칸 우선순위 평가 로직 구현
- 상대 점수와 최근 베팅 흐름을 고려한 베팅 전략 구현
- 반복 시뮬레이션을 통한 휴리스틱 조정
